# agentic-ai-job-alert-automation
An Agentic AI workflow using n8n and Gemini API to scrape, filter, deduplicate, and deliver daily Python startup jobs to Telegram
✨ Key Features

- 🔍 **Multi-Portal Search:** Automatically scans Python Developer roles across Naukri and LinkedIn.
- 🧠 **AI-Powered Startup Filtering:** Uses Gemini AI Agent to exclude MNCs and isolate early-stage startups in Chennai & Chengalpattu.
- ⚡ **Deduplication Logic:** Uses unique job links to prevent repeat notifications.
- ⏰ **Scheduled Alerts:** Configured with `Schedule Trigger` to run daily at 11:00 AM IST.
- 💬 **Telegram Integration:** Sends clean Markdown notifications with direct apply links to Telegram.

---

## 🛠 Tech Stack

- **Automation:** n8n
- **AI Model:** Google Gemini (PaLM) AI Agent
- **Messaging:** Telegram Bot API
- **Logic:** JavaScript (Code Node) & Deduplication Node
